# Traps

- **This is vendored upstream code, not PVH code.** 264 inputs and 96 outputs. Editing it forks the estate from upstream and makes the module un-upgradable — a needed change here is an escalation, not an edit.
- Its submodules carry their own `moved` blocks in `migrations.tf` files. Those belong to upstream's own refactors; removing one turns an upstream rename into a destroy-and-recreate of a live node group.
- Node-group changes frequently force replacement. A replaced node group drains and recreates every node in it, evicting running CI jobs.
- Cluster version upgrades are one-way. Verify addon compatibility before planning one.
- `aws_eks_access_entry` governs who can reach the cluster API. Removing one revokes access on apply.
- Because the module is vendored, its behaviour is fixed at the vendored commit — do not reason about it from current upstream documentation without checking the copy in the repo.
