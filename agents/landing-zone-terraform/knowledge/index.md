# PVH Landing Zone Terraform knowledge bundle

This is the OKF bundle root for the read-only PVH Landing Zone Terraform agent.
It is not prompt-loaded. Only categories registered in `index.yaml` are loaded.

The bundle preserves the curated repository, module, shared-contract, and
evidence-validation concepts from the Terraform documentation workspace. Live
GitLab repository state remains authoritative; these concepts route evidence
collection and define stop conditions.

Archived reports and dated repository-refresh findings remain outside the
registered category paths so they cannot silently become current prompt facts.
