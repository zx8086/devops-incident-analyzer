The v2 pilot needs a second bootstrap (`bootstrap-v2.ts`) but must not duplicate the process-lifecycle machinery. This extraction isolates everything that doesn't touch the v1 `McpServer` type so F2 can share it. Planned as F1 in `~/.claude/plans/can-we-look-at-structured-crown.md`.

## Where the bodies are buried

All in `packages/shared/src/bootstrap.ts` (`createMcpApplication` at :98):

- `:105-123` — `uncaughtException` / `unhandledRejection` process handlers, registered at function entry, **skipped when `options.embedded`** (SIO-986: the KG server mounts in-process in the web app; process-global handlers would take the host down). The embedded semantics at `:82-89` are the subtlest contract here — preserve exactly.
- `:140` area — tool-call metrics recorder lifecycle (SIO-1400): recorder created ONCE per process, closed in shutdown; `installToolCallLogging` wiring at `:181` (the install itself is v1-coupled — stays OUT of the lifecycle module; only the recorder open/close ownership moves).
- `:192` — `buildIdentityCard(...)` (from `./transport/identity.ts`) — SDK-agnostic, moves.
- `:268-271` — SIGINT/SIGTERM registration, again embedded-gated.
- `OAuthRequiresInteractiveAuthError` handling (import at `:4`) — the rethrow-vs-exit branching on `embedded`.
- Telemetry init/shutdown ordering (init before server start, shutdown after close).

What must NOT move: anything typed against `McpServer`/v1 transports — server construction, transport wiring, `installReadOnlyChokepoint`/`installToolCallLogging` calls (both monkey-patch v1-private `server.server._requestHandlers` — see `read-only-chokepoint.ts:37-45`, `tool-call-logging.ts:47,124`; F2 rebuilds those against v2's public seam).

## The fix (step-by-step)

1. Branch off `origin/main`. Read `bootstrap.ts` fully; also `packages/shared/src/__tests__/bootstrap.test.ts` + `bootstrap.identity.test.ts` — these are the regression net and must pass UNCHANGED (do not edit them; if an edit seems needed, the extraction is wrong).
2. Create `packages/shared/src/bootstrap-lifecycle.ts` exporting a small surface, e.g. `installProcessLifecycle({ embedded, log, onShutdown })` (returns an uninstall/shutdown-runner), `openMetricsRecorder(...)` ownership helper, and re-hosting the telemetry init/shutdown ordering + `OAuthRequiresInteractiveAuthError` branch + `buildIdentityCard` passthrough. Signature design is free WITHIN shared-internal (not exported from the package barrel — keep it internal; F2 imports by path).
3. Rewire `createMcpApplication` to consume it. Pure code motion plus seam introduction — zero behavior deltas, including handler registration ORDER (handlers register at function entry, before any await — preserve).
4. Verify per acceptance criteria below.
