## Risks and edge cases

| Risk | Likelihood | Mitigation |
|---|---|---|
| Token minted in prd while the hub polls dev, analyzer gets 401 | High if step 1 runs as chosen | Surfaced to the user twice; `token-list` on dev shows the live directory; re-mint in dev takes one command |
| Synchronous action route holds a browser request for up to 15 min on investigate | Medium | Budgets are env-tunable; async polling is listed as a follow-up in the spec |
| Spoke replies parseable but off-schema | Medium | Zod rejects, card shows "schema mismatch", nothing retried; spoke persona bullet in #91 tells agents the exact shape |
| Greptile keeps skipping after a fix push | High until dashboard fixed | Merge gate stays unsatisfied; do not merge on SKIPPED for code |
| Mailbox sends to `ops` are never answered to the analyzer | By design | Card says queued; the #91 guide tells operators to forward to the right spoke |

## Out of scope for SIO-1635

Feeding the verdict into later conversation turns; persistent peer registration so spokes can push to the analyzer; async action execution with server-side polling; verification for non-AWS data sources; any pi-coms hub code change.
